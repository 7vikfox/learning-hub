🚀 Project Example

📝 Smart Task Manager (CLI)

A simple command-line application to manage daily tasks.

Features:
  • Add new tasks
  • View all tasks
  • Mark tasks as completed
  • Delete tasks
  • Save data using JSON

▶️ How to Run
