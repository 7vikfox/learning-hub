📘 DSA Basic Notes

Data Structures & Algorithms – Quick Revision Sheet

📌 1. What is DSA?

Data Structures and Algorithms (DSA) is the study of organizing data efficiently and solving problems using step-by-step procedures.

🧠 2. Time & Space Complexity

  • Time Complexity: Measures execution time (Big-O notation)
  • Space Complexity: Measures memory usage

Common complexities:

  • O(1) → Constant
  • O(log n) → Logarithmic
  • O(n) → Linear
  • O(n²) → Quadratic

📊 3. Basic Data Structures

📍 Arrays

Collection of elements stored in continuous memory locations.

📍 Linked List

Elements stored in nodes, each pointing to the next node.

📍 Stack (LIFO)

Last In First Out. Example: Undo operation.

📍 Queue (FIFO)

First In First Out. Example: Ticket counter.

📍 Hash Table

Stores key-value pairs for fast access.

🔁 4. Basic Algorithms

🔍 Searching

  • Linear Search → O(n)
  • Binary Search → O(log n)

🔃 Sorting

  • Bubble Sort
  • Selection Sort
  • Insertion Sort
  • Merge Sort → O(n log n)

🧩 5. Important Concepts

  • Recursion
  • Greedy Algorithms
  • Dynamic Programming
  • Backtracking

⚡ Quick Tips

  • Always analyze time complexity before coding
  • Practice problems daily (LeetCode / Codeforces)
  • Understand logic, don’t memorize solutions
